# Diccionario de Datos · BarberFlow

**Motor:** PostgreSQL 16 · **ORM:** Spring Data JPA / Hibernate 6 · **Migraciones:** Flyway (`V1__esquema_inicial.sql`).

Este diccionario describe las **22 tablas** del sistema. Cada fila trae el tipo SQL exacto, sus restricciones y la anotación JPA con la que se mapea, de modo que coincide con el script SQL y con las clases `@Entity` del backend.

## Convenciones y decisiones de diseño

| Tema | Decisión | Motivo |
|---|---|---|
| Claves primarias | `BIGINT GENERATED BY DEFAULT AS IDENTITY` | Simple, eficiente y compatible con `GenerationType.IDENTITY`. |
| Dinero | `NUMERIC(12,2)` / `BigDecimal` | Nunca punto flotante (RNF-07, RN-09). |
| Cantidades de insumos | `NUMERIC(12,3)` | Permite fracciones de g o ml. |
| Enumeraciones | `VARCHAR` + `CHECK` y `@Enumerated(EnumType.STRING)` | Legible, seguro ante reordenamientos del enum. |
| Fechas | `TIMESTAMP` en hora local del establecimiento | Cada establecimiento guarda su `zona_horaria`. |
| Herencia de usuarios | `JOINED`: `usuario` + `cliente` / `profesional` / `administrador` | Los hijos comparten PK con `usuario`. |
| Carga de relaciones | Todas `FetchType.LAZY` | Evita consultas innecesarias (N+1); se usa `@EntityGraph` cuando se requiere. |
| Multi-establecimiento | Cada dato de negocio cuelga de `id_establecimiento` | Aislamiento entre negocios (RF-02). |
| Citas superpuestas | `EXCLUDE USING gist` con `tsrange` (en SQL) | Última barrera ante reservas simultáneas (RNF-07). |
| Doble cobro | Índice único parcial `uq_pago_cita_aprobado` | Una cita solo puede tener un pago `APROBADO` (RN-03); permite reintentar tras un rechazo. |

> **Nota:** `cliente` puede existir sin cuenta de acceso (RF-13), por eso `correo` y `hash_clave` aceptan NULL en `usuario`; la restricción `ck_usuario_acceso` obliga a tenerlos a todos los demás roles.

## establecimiento

**Entidad:** Establecimiento · **Descripción:** Unidad de negocio (tenant). Aísla los datos de cada barbería, peluquería, spa o salón (RF-02).

| Columna | Tipo SQL | Restricciones | Descripción funcional | Mapeo ORM |
|---|---|---|---|---|
| `id_establecimiento` | `BIGINT` | IDENTITY, PK | Identificador único (autogenerado). | `@Id @GeneratedValue(strategy = IDENTITY)` |
| `nombre` | `VARCHAR(120)` | NOT NULL | Nombre comercial. | `@Column(nullable = false, length = 120)` |
| `nit` | `VARCHAR(20)` | NOT NULL, UNIQUE | NIT del negocio; no se repite entre establecimientos. | `@Column(nullable = false, unique = true, length = 20)` |
| `tipo` | `VARCHAR(20)` | NOT NULL, CHECK `tipo IN ('BARBERIA', 'PELUQUERIA', 'SPA', 'SALON_UNAS')` | Tipo de negocio. | `@Enumerated(STRING)` |
| `direccion` | `VARCHAR(200)` | NOT NULL | Dirección física. | `@Column(nullable = false, length = 200)` |
| `ciudad` | `VARCHAR(80)` | NOT NULL | Ciudad. | `@Column(nullable = false, length = 80)` |
| `telefono` | `VARCHAR(20)` | NOT NULL | Teléfono de contacto. | `@Column(nullable = false, length = 20)` |
| `zona_horaria` | `VARCHAR(40)` | NOT NULL, DEFAULT `'America/Bogota'` | Zona horaria del negocio. | `@Column(name = "zona_horaria", nullable = false, length = 40)` |
| `anticipacion_min_horas` | `INT` | NOT NULL, DEFAULT `2`, CHECK `anticipacion_min_horas >= 0` | Horas mínimas de anticipación para modificar o cancelar una cita (RN-08). | `@Column(name = "anticipacion_min_horas", nullable = false)` |
| `estado` | `VARCHAR(15)` | NOT NULL, DEFAULT `'ACTIVO'`, CHECK `estado IN ('ACTIVO', 'SUSPENDIDO')` | Estado del establecimiento en la plataforma. | `@Enumerated(STRING)` |

## usuario

**Entidad:** Usuario (abstracta) · **Descripción:** Tabla raíz de la herencia: identidad y autenticación de todas las personas (RF-01). Se implementa con `InheritanceType.JOINED`.

| Columna | Tipo SQL | Restricciones | Descripción funcional | Mapeo ORM |
|---|---|---|---|---|
| `id_usuario` | `BIGINT` | IDENTITY, PK | Identificador único (autogenerado). | `@Id @GeneratedValue(strategy = IDENTITY)` |
| `nombres` | `VARCHAR(80)` | NOT NULL | Nombres. | `@Column(nullable = false, length = 80)` |
| `apellidos` | `VARCHAR(80)` | NOT NULL | Apellidos. | `@Column(nullable = false, length = 80)` |
| `correo` | `VARCHAR(150)` | UNIQUE | Correo en minúsculas. Puede ser NULL solo para clientes atendidos de forma presencial (RF-13). | `@Column(unique = true, length = 150)` |
| `telefono` | `VARCHAR(20)` | NOT NULL, UNIQUE | Celular. Permite detectar clientes duplicados (CU17). | `@Column(nullable = false, unique = true, length = 20)` |
| `hash_clave` | `VARCHAR(100)` | NULL permitido | Hash BCrypt de la contraseña. NULL = cliente sin cuenta de acceso. | `@Column(name = "hash_clave", length = 100)` |
| `rol` | `VARCHAR(15)` | NOT NULL, CHECK `rol IN ('CLIENTE', 'PROFESIONAL', 'ADMINISTRADOR')` | Rol principal del usuario. | `@Enumerated(STRING)` |
| `estado` | `VARCHAR(15)` | NOT NULL, DEFAULT `'ACTIVO'`, CHECK `estado IN ('ACTIVO', 'BLOQUEADO', 'INACTIVO')` | Estado de la cuenta. | `@Enumerated(STRING)` |
| `intentos_fallidos` | `INT` | NOT NULL, DEFAULT `0`, CHECK `intentos_fallidos >= 0` | Intentos de inicio de sesión fallidos consecutivos (bloqueo a los 5, RF-01). | `@Column(name = "intentos_fallidos", nullable = false)` |
| `bloqueado_hasta` | `TIMESTAMP` | NULL permitido | Fecha y hora hasta la que la cuenta está bloqueada. | `@Column(name = "bloqueado_hasta")` |
| `fecha_registro` | `TIMESTAMP` | NOT NULL, DEFAULT `now()` | Fecha de creación de la cuenta. | `@Column(name = "fecha_registro", nullable = false, updatable = false)` |

**Restricciones de tabla:**

- `ck_usuario_acceso`: CHECK (rol = 'CLIENTE' OR (correo IS NOT NULL AND hash_clave IS NOT NULL))

## horario

**Entidad:** Horario · **Descripción:** Jornada laboral semanal de un profesional, con descanso opcional (RF-05).

| Columna | Tipo SQL | Restricciones | Descripción funcional | Mapeo ORM |
|---|---|---|---|---|
| `id_horario` | `BIGINT` | IDENTITY, PK | Identificador único (autogenerado). | `@Id @GeneratedValue(strategy = IDENTITY)` |
| `id_profesional` | `BIGINT` | NOT NULL, FK → `profesional(id_usuario)`, ON DELETE CASCADE | Profesional dueño del horario. | `@ManyToOne(fetch = LAZY, optional = false) @JoinColumn(name = "id_profesional")` |
| `dia_semana` | `VARCHAR(10)` | NOT NULL, CHECK `dia_semana IN ('MONDAY', 'TUESDAY', 'WEDNESDAY', 'THURSDAY', 'FRIDAY', 'SATURDAY', 'SUNDAY')` | Día de la semana (`java.time.DayOfWeek`). | `@Enumerated(STRING)` |
| `hora_inicio` | `TIME` | NOT NULL | Inicio de la jornada. | `@Column(name = "hora_inicio", nullable = false)` |
| `hora_fin` | `TIME` | NOT NULL | Fin de la jornada. | `@Column(name = "hora_fin", nullable = false)` |
| `descanso_inicio` | `TIME` | NULL permitido | Inicio del descanso (opcional). | `@Column(name = "descanso_inicio")` |
| `descanso_fin` | `TIME` | NULL permitido | Fin del descanso (opcional). | `@Column(name = "descanso_fin")` |
| `vigente_desde` | `DATE` | NOT NULL | Fecha desde la que rige este horario. | `@Column(name = "vigente_desde", nullable = false)` |

**Restricciones de tabla:**

- `ck_horario_jornada`: CHECK (hora_fin > hora_inicio)
- `ck_horario_descanso`: CHECK ((descanso_inicio IS NULL AND descanso_fin IS NULL) OR (descanso_inicio IS NOT NULL AND descanso_fin IS NOT NULL AND descanso_fin > descanso_inicio AND descanso_inicio >= hora_inicio AND descanso_fin <= hora_fin))

**Índices:**

| Índice | Columnas | Tipo | Consulta que optimiza |
|---|---|---|---|
| `idx_horario_prof_dia` | `id_profesional, dia_semana, vigente_desde DESC` | compuesto | Obtener el horario vigente de un profesional para un día (RF-07). |
